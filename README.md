# ...
Автоматическое заполнение тегов: Скрипт извлекает исполнителя и название песни напрямую из имен файлов (например, Woodkid – Iron.mp3) и записывает их в ID3-теги.

Рекурсивный поиск: Полная поддержка обхода вложенных папок — достаточно указать корневую директорию ~/Music.

Исправление «битых» файлов: Решает проблему отсутствия ID3-заголовков (doesn't start with an ID3 tag), принудительно создавая структуру тегов там, где её не было.

Интеллектуальная очистка: Удаляет порядковые номера треков (например, «01. », «05 - ») из начала имени, чтобы в поле «Исполнитель» попадали только корректные данные.

Совместимость с кириллицей: Принудительное использование стандарта ID3v2.3, что гарантирует корректное отображение русских букв в любых плеерах и файловых менеджерах (GNOME/Nautilus).

## Установка
1. git clone .
2. Установите зависимости: `pip install -r requirements.txt`.

## Использование
python main.py ~/Music
